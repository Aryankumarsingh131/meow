# JWT/JOSE verification for services/api/app/auth.py.
# Chosen because it was already installed, so T06 added no new supply-chain
# surface. 3.5.0 is the release that fixes CVE-2024-33663 (algorithm
# confusion) and CVE-2024-33664 (JWE decompression bomb) - do not downgrade.
# Known limitation, measured in tests/auth_test.py and worked around in
# auth.py: this library ignores the JWS `kid` header and walks the JWKS key
# set in order. auth.py therefore selects the key by `kid` itself.
# Migration path: PyJWT is the better-maintained option; switching touches
# only verify_token() and needs no test changes. See docs/auth-provider.md.
python-jose==3.5.0
cryptography==49.0.0   # RSA backend for python-jose; also used by the tests

# PostgreSQL DB-API driver used by sync/source persistence. The binary extra
# keeps the pinned Windows/Linux development path independent of system libpq.
psycopg[binary]==3.3.6

# T16: decode-level validation of uploaded images (magic bytes alone are not
# enough). Already installed on the build host - no new download. Licence:
