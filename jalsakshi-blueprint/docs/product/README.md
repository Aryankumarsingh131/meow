# Product specification index

[User journeys](user-journeys.md) define the operational sequence, including exceptional paths. [UI specification](ui-ux-specification.md) maps real screens to data, APIs, accessibility and interaction states.

A screen is not complete if it merely renders seeded success data. Its empty, offline, invalid, unauthorized and partially synchronized states must also work. Generated concept images may illustrate the pitch but never appear as real test evidence.
