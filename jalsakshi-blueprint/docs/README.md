# Documentation map

The root [README](../README.md) is the complete artifact index. Start with [project brief](project-brief.md), [requirements](requirements.md) and [assumptions](assumptions-and-open-questions.md).

- [Research](research/README.md): evidence, limitations, decisions and learning.
- [Architecture](architecture/README.md): components, state and contracts.
- [Product](product/README.md): workflows and screens.
- [Engineering verification](engineering/testing-and-evaluation.md): release tests and ML evaluation.
- [Acceptance](delivery/acceptance-criteria.md): what distinguishes a demo, pilot and production product.
- [Agent source of truth](agent-workflow/source-of-truth.md): authority, ownership and conflict resolution.

Interpretation labels: **FACT** = directly verified source or workspace observation; **REPORTED** = a study's finding, not reproduced here; **INFERENCE** = engineering judgment; **ASSUMPTION** = unresolved input; **EXPERIMENT** = proposed validation; **MEASURED** = result from this project with recorded evidence. Currently there are no MEASURED app results.
